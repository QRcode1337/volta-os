# JEV audit: template spec vs VOLTA (2026-10-28)

Scope: how the copied "Jay E / RoboNuggets Agentic OS" files describe **Jev**, what VOLTA actually runs, the gaps between them, and what was changed. Nothing is committed.

## 1. What the files say JEV is

Sources: `workspace/product/jev-router.md`, `workspace/CLAUDE.md` §3, `workspace/AGENTS.md:13`, `workspace/MEMORY.md:25`, `workspace/departments/product.md:3,8`, 17 `workspace/skills/*/SKILL.md` ("Routed through Jev; default tier X at Y effort"), `HANDOFF_SPEC.md:14,115,176,239,268`, `MICRO_APPS_SPEC.md:106,173` (mock content only), `INTEGRATION_CONTRACTS.md:20,31,61`, `docs/HANDOFF.md:15,25,26,35,41,53,59`, Pathfinder `01-flowcharts/{platform,feeds,podcast,research}.md`, `02-duplication-report.md` §13 "Two JEVs", `03-unified-proposal.md` U12, `04-handoff-prompts.md:165`.

- **What it is.** An ultra-fast classifier (≈0.006 s, ≈$0.00004 per call) that picks HAIKU / SONNET / OPUS for every prompt or skill. The template's version is a simulation: `POST /api/jev-router` with "deterministic keyword heuristics" (`INTEGRATION_CONTRACTS.md:61`, `HANDOFF_SPEC.md:115`).
- **Heuristic** (`jev-router.md`):
  1. Keyword lanes: lightweight → HAIKU, drafting/analysis → SONNET, taste/motion/strategy/long-horizon → OPUS.
  2. Length: <160 chars nudges HAIKU, >1,200 chars nudges OPUS.
  3. The skill's frontmatter tier adds weight.
  4. Confidence is the winning lane's share. Jev overrides the requested tier only at **≥0.80**.
- **Rules** (`workspace/CLAUDE.md` §3):
  - Every skill call is classified first.
  - FABLE is never auto-selected; it is a manual pin.
  - Bias to the cheapest tier: "if Haiku can do it, Haiku does it".
  - Skill notes `grammar`/`note` rc-5 add a `jev: prefer-haiku` hint.
- **Touchpoints the specs name:**
  - Skills Deck ▶ → `/api/skills/run` → the report modal shows "model routed via Jev" (`HANDOFF_SPEC.md:176`).
  - Usage bar drawer: **"Jev Router Status Pill: `JEV 5.5 ACTIVE · 4,451 routes · $0.18 total`"** (`HANDOFF_SPEC.md:268`).
  - `/api/cache-status` carries `jev {routes,totalUsd,haikuPct}` (`types/os.ts:152`).
  - Skills analytics leaderboard: a "JEV ROUTED" badge plus an "Optimize to Haiku/Sonnet" button (`HANDOFF_SPEC.md:239`).
  - VOLTA-specific additions (`docs/HANDOFF.md`): Feeds JEV triage (:26, :53 "too many needs-action"), Podcast JEV rank (:41), ⌘K search "JEV re-rank" (:25), and "cache-status still shows mock 'simulated' Jev numbers" (:59).
- **Telemetry and cost.** The template baseline is invented: "4,451 calls · $0.18 · 41% Haiku · 37% Sonnet · 22% Opus". `docs/HANDOFF.md:35` puts telemetry at `/Volumes/Windsor/VOLTA/jev/telemetry.json`.
- **Fallback.** The heuristic itself is the whole template implementation.
- **Pathfinder U12.** Move `app/api/jev-router/jev.ts` to `lib/server/jev/heuristic.ts` and update its two importers.

## 2. What VOLTA does (before this change)

- **Real client**
  - `src/lib/server/jev/client.ts:71-118` is the TypeSafe System One client: `POST {base}/v1/systemone` with a Bearer key from `TYPESAFE_JEV_API_KEY` (server-only, never logged).
  - It makes 2 attempts within the deadline (8 s default, `:38`).
  - Two breakers: 3 failures open it for 30 s (`:48`), and a 401/403 opens it for 5 min (`:49`, using the shared `breaker()`).
  - `ask()` (`:126`) adds a 6 h / 500-entry LRU (`cache.ts:5-6`) and in-flight dedupe (`cache.ts:46`).
  - Operations: `route` (`:162`), `rank` (`:186`, Score per item in batches of 8, 4 in parallel), `triage` (`:212`, Choice per item) and `judge` (`:236`, noul checks).
- **Tier routing.** `tier.ts:27` `routeTier()` asks one Choice question over HAIKU/SONNET/OPUS: "the cheapest one that will do the task well".
- **Heuristic layer.** `app/api/jev-router/jev.ts` holds `classify()` (the spec heuristic, used only as the labelled fallback), `routeAndRecord()` (real JEV, falling back to the heuristic) and `resolveRoutedModel()` (FABLE pin plus the 0.80 gate).
- **Telemetry**
  - `telemetry.ts` keeps an in-memory mirror and flushes it (debounced, atomic) to Windsor.
  - It records requests, cache hits, errors, fallbacks, tokens, measured USD ($0.042/Mtok of input), latency p50/p95, `byOp` and `byTier`.
- **Routes.** `GET /api/jev-router` returns telemetry, detail and status (configured, circuit). `POST` returns a `JevRouteResult` with its source (jev / cache / fallback).
- **Callers**
  - `api/skills/run/route.ts:152`: every dashboard skill run is routed, and `resolveRoutedModel` gates the override.
  - `feeds/triage.ts:63`: fire-and-forget triage of untriaged items, 32 × 8 per trigger, labels cached forever in `triage.json`.
  - `podcast/rank.ts:75-86`: JEV scores the top 60 candidates (30 s timeout) and blends 50/50 with heuristics; it is skipped silently if JEV fails.
  - `research/search.ts:90-111`: opt-in re-rank of the top 30, 6 s, with secrets redacted.
  - `api/podcast/status`: key presence only.
- **UI**
  - `ExecutionReportModal.tsx:159` shows a "JEV ROUTED" stat, and the report markdown includes the Jev line.
  - The Feeds top bar has a JEV on/pending/paused chip (`FeedsApp.tsx:266`), and items carry a triage badge with a "jev" marker.
  - Research has a "JEV re-rank" toggle. The podcast episode view shows the per-story JEV score.
  - **Nothing read `GET /api/jev-router`.**
- **Live check (2026-10-28)**
  - `GET :50000/api/jev-router` → configured `true`, circuit closed.
  - `TYPESAFE_JEV_API_KEY` is set.
  - Telemetry since 2026-10-25 (persisted to Windsor): **106 requests, $0.01226 total**. By operation: triage 72, rank 33, route 1, judge 0. 3 cache hits, 0 errors, 0 fallbacks, p50 177 ms, p95 709 ms. Only 2 tier decisions, both OPUS.
  - Feeds `triage.json` holds 350 labels (v2): 81 needs-action (17 of them under 0.5 confidence, minimum 0.16), 99 fyi, 170 noise.

## 4. Implemented (smallest changes, shared modules)

1. **U12 move.** `src/app/api/jev-router/jev.ts` → `src/lib/server/jev/heuristic.ts`.
   - Relative imports, so there is no self-import of the barrel.
   - It is exported from `src/lib/server/jev/index.ts`.
   - Importers updated: `src/app/api/jev-router/route.ts`, `src/app/api/skills/run/route.ts` and `src/app/api/cache-status/route.ts`. The comment in `tier.ts` was also updated.
   - The old file is deleted and no shim is left.
2. **Skill prior.** `routeAndRecord(prompt, command, prior?)` passes the prior to `classify()` on fallback. `skills/run` passes the requested tier (the skill's frontmatter / matrix cell).
   - Real JEV is still asked unbiased; the prior keeps winning there through the 0.80 gate.
   - The report line now prints `JEV_OVERRIDE_THRESHOLD` instead of a hard-coded 0.80.
3. **`/api/cache-status`** reports real JEV data: `simulated:false`, `configured`, `circuitOpen`, `routes`, `requests`, `totalUsd` (6 dp) and `since`.
4. **Feeds triage tightening** (`src/lib/server/feeds/triage.ts`). A needs-action guess under `NEEDS_ACTION_MIN = 0.5` is stored as the likelier of fyi/noise, using JEV's own probabilities.
   - This applies to newly triaged items.
   - The 17 existing low-confidence needs-action labels stay until `TRIAGE_VERSION` (in `feeds/store.ts`, outside this scope) is bumped. Re-triaging 350 items costs about $0.005.
5. **JEV status pill.** New `src/components/jev/JevStatusPill.tsx`.
   - It reads `GET /api/jev-router` through `useSharedJson` every 60 s. That GET is telemetry only and never a paid call.
   - Display: "JEV ACTIVE · N routes · M calls · $X", "JEV PAUSED" when the circuit is open, or "JEV OFF" with no key.
   - The tooltip shows the tier split, per-op counts, cache hits, errors, p50/p95, measured spend and last error.
   - It is mounted in the Usage drawer header and **renders only while the drawer is open**: `src/components/mods/UsageRoboBar.tsx:14,705`. **This is the only edit outside the agreed file list.**
