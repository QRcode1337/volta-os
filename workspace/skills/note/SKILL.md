# /note

Capture a note into the right department file in the Second Brain.

## When to use
- Explicitly by command (`/note <text>`) or by another skill that needs to persist a fact.
- Tier routed by JEV (see `product/jev-router.md`); default **HAIKU** at **LOW** effort.

## Steps
1. Classify the note into one department (business·EPSILON, content·TST, research, agents, product·VOLTA, personal).
2. Pick the most specific existing file from that department's router; create one only if nothing fits.
3. Append under a dated heading. Keep the user's words; fix only obvious typos.
4. Add a one-line index card to `MEMORY.md` if the note introduces a new entity (prospect, project, channel, person).
5. Never store secrets or private personal details (health, family, legal, finances).
